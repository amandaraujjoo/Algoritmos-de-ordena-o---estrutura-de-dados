# Exercícios de Algoritmos de Ordenação

Este repositório contém uma série de exercícios que implementam diferentes algoritmos de ordenação. O objetivo é entender e comparar as abordagens clássicas e suas eficácias na organização de dados.

## Algoritmos Implementados

Os seguintes algoritmos de ordenação estão implementados neste repositório:

- **Bubble Sort**
- **Selection Sort**
- **Insertion Sort**
- **Merge Sort**
- **Quick Sort**
